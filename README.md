# SALOON DREEM — نظام إدارة صالون الحلاقة

تطبيق عربي باتجاه RTL لإدارة الحجوزات، الحلاقين، الخدمات والأسعار، العملاء، التحصيلات المالية والمصروفات، والإعدادات. يعتمد على **FastAPI + SQLite** مع واجهة ويب متجاوبة وتجهيزات PWA ونسختين قابلتين للبناء على Windows وAndroid.

**الإصدار الحالي: 1.2.2 — نسخة مرشحة للاستعادة والتوزيع.** أُعيد تجميع شجرة مصدر قابلة للتشغيل بعد اكتشاف أن حزم المصدر القديمة لم تعد سليمة بالكامل. استُخدمت الملفات التي اجتازت فحص CRC، بينما تستخدم الواجهة حزمة JavaScript المولّدة \`frontend/app.js\` لأن ملف TypeScript الأصلي لم يمكن استعادته بثقة.

## الميزات

- لوحة إدارة: ملخص، المواعيد والتقويم، العملاء، فريق الحلاقين، الخدمات والأسعار، المالية والصندوق، التقارير، والإعدادات.
- بوابة عميل لاستعراض الخدمات وإنشاء حجز ومراجعة ملف العميل المحلي.
- إعداد أول حساب مدير، تسجيل الدخول، تغيير كلمة المرور وإبطال الجلسات القديمة.
- التحقق من توافر الموعد ومنع التعارض، وتسجيل التحصيل مرة واحدة، وملخص مالي وتصدير CSV.
- واجهة عربية RTL، تصميم متجاوب، الوضع الفاتح والداكن، وتخزين غلاف الواجهة الثابت عبر Service Worker.
- تصدير CSV مع تعقيم الخلايا التي قد تُفسّر كمعادلات، ومعاملات SQLite لحماية فحوصات الحجوزات والتحصيلات من بعض حالات التزامن.

## تشغيل المشروع على Windows من المصدر

ثبّت Python 3.12 أو 3.13 وNode.js 22.12 أو أحدث، ثم افتح PowerShell في مجلد المشروع:

\`\`\`powershell
Set-ExecutionPolicy -Scope Process Bypass
.\RUN-SALOON-DREEM.ps1
\`\`\`

أو شغّل \`RUN-SALOON-DREEM.bat\`. افتح \`http://127.0.0.1:8000\` وأنشئ حساب المدير عند أول تشغيل؛ لا توجد كلمة مرور افتراضية. أضف حلاقًا نشطًا وخدمات وأسعارًا قبل استقبال حجوزات حقيقية.

## ملف Windows المحمول

يُنتج البناء الملف \`SALOON-DREEM-Portable-1.2.2.exe\` بعد تجميع خادم FastAPI ودمجه مع Electron. لا يتطلب مثبتًا تقليديًا، لكن قاعدة بيانات Windows تُحفظ في مجلد بيانات المستخدم الخاص بالتطبيق وليس بجانب الملف التنفيذي؛ نسخ EXE إلى جهاز آخر لا ينقل بيانات الجهاز الأصلي تلقائيًا. الملف غير موقّع بشهادة ناشر تجارية، لذا قد يعرض Windows SmartScreen تنبيهًا.

## تطبيق Android — APK للهواتف

**التنزيل المباشر:** [SALOON-DREEM-Android-1.2.2-debug.apk](https://github.com/ibrahimrsaleem-wq/SALOON-DREEM/releases/download/v1.2.2/SALOON-DREEM-Android-1.2.2-debug.apk)  
[صفحة الإصدار على GitHub](https://github.com/ibrahimrsaleem-wq/SALOON-DREEM/releases/tag/v1.2.2)

### التثبيت على الهاتف

1. افتح رابط APK من الهاتف ونزّل الملف.
2. افتح الملف من التنزيلات، واسمح بالتثبيت من هذا المصدر إذا طلب Android ذلك.
3. أكمل التثبيت ثم افتح **SALOON DREEM**.
4. للاتصال بخادم الصالون، افتح **إعداد الاتصال بالخادم** في شاشة الدخول وأدخل عنوان HTTPS للخادم ثم احفظه.

### ما الذي تحتاجه لكي تعمل البيانات والحجوزات عبر الهاتف؟

هذا APK حزمة Android قابلة للتثبيت والاختبار الجانبي، وليست إصدار Google Play موقّعًا. تحتاج الوظائف التي تحفظ أو تسترجع بيانات الصالون إلى خادم API منشور يمكن الوصول إليه من الهاتف عبر HTTPS. لم يُرفق بالمشروع عنوان خادم إنتاج عام، لذلك لن يعمل الاتصال بالبيانات عن بُعد حتى تُدخل عنوان خادمك الفعلي. ترك العنوان فارغًا لا ينشئ خادمًا ولا يزامن بيانات الهاتف مع قاعدة بيانات الكمبيوتر تلقائيًا.

لا تضع كلمات مرور أو مفاتيح سرية في رابط الخادم أو داخل ملفات المصدر. قبل استخدام بيانات عملاء حقيقية، اختبر الاتصال والنسخ الاحتياطية على خادم تملكه.

## الحدود المعروفة قبل الاستخدام التجاري

- التحصيل الحالي تسجيل محاسبي داخلي، وليس بوابة دفع إلكتروني أو معالجة بطاقات.
- لا توجد تكاملات فعّالة لـ SMS/OTP أو WhatsApp أو Google Calendar في هذا الإصدار.
- يعتمد جزء من ملف العميل والمكافآت على التخزين المحلي للمتصفح؛ مزامنة هوية عميل موثقة عبر الأجهزة تحتاج تطويرًا إضافيًا.
- SQLite مناسبة للتشغيل المحلي أو الاستخدام المحدود. النشر العام أو متعدد الفروع يتطلب خادمًا موثوقًا، HTTPS، نسخًا احتياطية مجرّبة، ومراقبة وتحديد معدل مركزيًا.
- لم تُستعد كل الملفات الأصلية بعد تلف بعض الأرشيفات. راجع \`AUDIT-REPORT-1.2.2.md\` لمعرفة ما جرى التحقق منه وما لا يزال مطلوبًا.
- الاختبارات الآلية لا تغني عن تجربة قبول يدوية على أجهزة Windows وAndroid ومراجعة أمنية قبل استخدام بيانات حقيقية.

### إنشاء اختصار على سطح المكتب
بعد فك حزمة التوزيع إلى مجلد دائم، شغّل `scripts/Create-Desktop-Shortcut.ps1` من PowerShell لإنشاء اختصار باسم SALOON DREEM بأيقونة التطبيق. قاعدة البيانات محفوظة في مجلد بيانات المستخدم الخاص بالتطبيق ولا تنتقل تلقائيًا بمجرد نسخ EXE إلى جهاز آخر.

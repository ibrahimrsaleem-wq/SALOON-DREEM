# حالة البناء والتحقق — SALOON DREEM 1.2.0

آخر مراجعة: 28 أكتوبر 2026.

## تم التحقق منه الآن داخل بيئة التطوير

- `PYTHONPATH=. python -m pytest -q tests`: **12 اختبارًا ناجحًا**.
- `python -m compileall -q backend server.py`: نجاح.
- `node --check frontend/app.js`, `desktop/main.cjs`, `frontend/runtime-config.js`, و`tools/configure-mobile.mjs`: نجاح.
- ملف `frontend/app.js` هو الملف المولّد من TypeScript؛ يجب تشغيل `npm run check:types` و`npm run build:web` بعد تثبيت npm dependencies.
- لم يُنتج EXE أو APK في بيئة Linux الحالية؛ يوجد workflow للبناء على GitHub Actions، ويجب التأكد من نجاحه بعد رفع المصدر.

## تحسينات الإصدار 1.2.0

- إبطال الجلسات السابقة عند تغيير كلمة المرور.
- حدّ محلي لمحاولات إعداد أول مدير وتسجيل الدخول والحجز العام. الحد يعمل لكل عملية تطبيق؛ عند استخدام عدة workers يلزم أيضًا حدّ عبر reverse proxy أو خدمة مركزية.
- فحص التعارض قبل إعادة تفعيل الموعد الملغى.
- تحييد صيغ الجداول الحسابية في CSV، والتحقق من تواريخ البحث.
- رؤوس أمان أساسية ومنع تخزين استجابات API في الذاكرة المؤقتة.

## لم يُبنَ بعد كملف تنفيذي

- **Windows Portable EXE:** يتطلب runner يعمل بنظام Windows واعتماديات Electron وPyInstaller.
- **Android APK:** إعداد Capacitor موجود لبناء Debug APK. يتطلب عنوان HTTPS للخادم عبر `MOBILE_API_BASE_URL` أو ضبط رابط الخادم من شاشة الدخول. هذه ليست نسخة متجر موقعة.
- **استضافة الإنتاج:** هذا المصدر لا يشمل خادمًا عامًا مستضافًا أو بوابة دفع/OTP أو تكاملات Google/WhatsApp؛ هذه تحتاج خدمات ومفاتيح رسمية واختبارات مستقلة.

## ملاحظة أمنية للنشر

حدّ المعدل الحالي داخل الذاكرة مناسب كحماية أولية لتشغيل محلي بعملية واحدة وليس بديلًا عن rate limiting مركزي في استضافة عامة. لا ترفع `.env` أو قاعدة البيانات أو `data/.token-secret` أو مفاتيح توقيع التطبيقات إلى GitHub.

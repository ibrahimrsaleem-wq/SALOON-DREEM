# حالة البناء والتحقق — SALOON DREEM 1.1.0

آخر مراجعة: 28 أكتوبر 2026.

## تم التحقق منه داخل بيئة التطوير

- `python -m pytest -q`: **7 اختبارات ناجحة**.
- `python -m compileall -q backend server.py`: نجاح.
- `npm run check:types`: نجاح.
- `npm run build:web`: نجاح، وتم توليد `frontend/app.js` من TypeScript.
- `npm run check:js`: نجاح لملفات JavaScript وElectron وإعداد الهاتف.
- فحص تشغيل سابق أكد استجابة `/api/health` وصفحة الويب وملف JavaScript وواجهة توثيق API.

## لم يُبنَ بعد كملف تنفيذي في هذه الجلسة

- **Windows Portable EXE:** إعداد GitHub Actions موجود، لكن لم ينتج EXE محليًا هنا؛ يتطلب البناء بيئة Windows واعتماديات Electron وPyInstaller. بعد رفع المصدر بنجاح، راقب workflow باسم `Build SALOON DREEM` ونزّل artifact `SALOON-DREEM-Windows-Portable`.
- **Android APK:** إعداد Capacitor وGitHub Actions موجود، لكن لم ينتج APK محليًا هنا. النسخة المهيأة هي APK للاختبار الجانبي (Debug)، وليست إصدار متجر موقّعًا. يلزم توفير عنوان API عبر متغير المستودع `MOBILE_API_BASE_URL` باستخدام HTTPS أو ضبط عنوان الخادم من شاشة الدخول.
- **GitHub:** حاولت الجلسة إنشاء ملف في المستودع المستهدف لكن خدمة GitHub رفضت الكتابة بصلاحية `403`. لذلك لا يُدّعى أن المصدر رُفع. استخدم `scripts/Publish-To-GitHub.ps1` من جهازك بعد تسجيل الدخول بحساب يملك صلاحية Write. السكربت يتوقف إذا لم يعد المستودع فارغًا ولا يستخدم `force push`.
